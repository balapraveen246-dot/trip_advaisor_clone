# 🌍 Tripadvisor Clone

A fully responsive **Tripadvisor Landing Page Clone** built as a **Hands-on Frontend Project** using **HTML5** and **CSS3**. This project was developed to strengthen my practical frontend development skills by recreating the modern Tripadvisor user interface with clean, responsive, and well-structured code.

## 🚀 Project Overview

This project focuses on gaining real-world experience in frontend web development through hands-on implementation. Every section was built from scratch to improve my understanding of responsive layouts, Flexbox, CSS positioning, spacing, and modern UI design principles.

## ✨ Features

- ✅ Fully Responsive Design
- ✅ Modern Navigation Bar
- ✅ Search Section
- ✅ Destination Cards
- ✅ Clean and Structured Layout
- ✅ Flexbox-Based Responsive Design
- ✅ Mobile-Friendly Interface
- ✅ Semantic HTML5 Structure
- ✅ Pure CSS Styling (No Frameworks)
